# 人生成就解锁 · 社畜宇宙第3弹

给普通日子发 Steam 风格成就弹窗——连续上班 1453 天，稀有度 12.4%。

## 在线使用

打开 `rensheng_chengjiu.html` 即可（纯本地运行），或访问：https://tzgj4r2kjd-commits.github.io/rensheng-chengjiu/rensheng_chengjiu.html

## 功能

- 输入你的成就，生成 Steam 风格金属徽章弹窗（弹入+扫光+粒子迸发+音效）
- 真实稀有度算法：类别基准 × 连续天数 × 历史重复度 × 难度词，不是随机数
- 隐藏成就彩蛋；连续解锁第 3 个有专属台词
- 社畜角色旁观：成就弹窗砸下时震惊脸，稀有成就变星星眼崇拜脸，解锁越多班味越重
- 数据仅存本地浏览器，不上传任何服务器

## 技术栈

单文件 HTML + 原生 JS + SVG/WebAudio/canvas，零依赖、断网可用。
